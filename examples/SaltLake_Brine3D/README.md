# 三维盐湖地下卤水补水溶矿基础算例

2026-08-16 的案例记录报告 `highres/feedback` 与 `highres/fixed` 已完成并通过验证。
模型配置和验证标准见下文；该历史记录不代表后续软件版本重新执行了这些情景。

本算例是一个理想化但可执行的三层承压反应运移模型，用于检验以下假设：蒸发盐溶解造成的孔隙率与水力传导系数增加，会把流量逐渐集中到少数路径，从而缩短补给水到采卤井的突破时间，并可能降低总体有效溶矿体积。

它不是特定矿区的校准模型。水化学、矿物动力学、渠床渗透性和含水层参数都是清楚记录的第一阶段假设，应用于工程预测前必须由现场资料替换并完成敏感性、网格和时间步收敛分析。

## 1. 模型结构

| 项目 | `smoke` | `base` | `highres`（默认） |
|---|---:|---:|---:|
| 网格 | 3 × 7 × 12（252 单元） | 3 × 15 × 30（1350 单元） | 3 × 30 × 60（5400 单元） |
| 尺寸 | 600 × 350 × 30 m | 1200 × 600 × 30 m | 1200 × 600 × 30 m |
| 时长/步数 | 2 年/24 个等长月步 | 30 年/360 个等长月步 | 30 年/120 个季度步 |
| 采卤井 | 第 1 层 3 口，每口 −60 m³/d | 第 1 层 5 口，每口 −120 m³/d | 第 1 层 9 口，总量 −600 m³/d |
| 输出 | 每年 | 每年 |

- 三层均采用 `icelltype=0`，不模拟潜水面移动。
- 初始水头与补水渠水位均为 35 m；其他外边界无流。
- 补水渠用第 1 层的 GHB 单元表示。入渗量由渠水位、地下水位和渠床电导共同决定，因此局部导水能力变化可以重新分配补水，而不是强制给定恒定补水量。
- 采卤渠不作为水力边界；只有 WEL 采卤井抽水，符合输卤渠防渗假设。
- 初始水平 K 由 GSTools 生成可复现的三维对数高斯随机场；`highres` 的 `std[ln(K/Kg)]=0.85`，相关尺度为 180、55、12 m，三层几何平均值为 3.0、1.2、0.5 m/d；`Kz/Kx=0.1`。
- 初始孔隙率为 0.25，比储水系数为 `1e-5 m⁻¹`。

## 2. 反应体系

算例复用 `examples/Hamann2015/input_data/pitzer.dat`，以 Pitzer 活度模型处理高离子强度卤水。传输组分包括 H、O、电荷残差、B、Br、Ca、Cl、K、Li、Mg、Na 和 S；结果文件额外直接输出所关注离子的 mol/L 浓度。

补给水先与石盐达到平衡，边界 Na 和 Cl 均约为 5.4 mol/L，因此石盐不会无条件主导溶解。Br 仅作为保守示踪剂，用于计算渠水到井的 5% 和 50% 突破时间。

名义地层由以下体积分数组成：

| 固相 | 体积分数 |
|---|---:|
| 石盐 Halite | 0.544 |
| 光卤石 Carnallite | 0.060 |
| 杂卤石 Polyhalite | 0.040 |
| 钾石盐 Sylvite | 0.005 |
| 石膏 Gypsum | 0.045 |
| 硼砂 Borax | 0.006 |
| 惰性骨架 | 0.050 |
| 初始孔隙 | 0.250 |

蒸发盐总体积分数为 0.70，按所用摩尔质量与摩尔体积换算，名义固相元素 K 品位为 2.20 wt%。另外设置约 1.54%、2.86% 的低/高钾微相带，但三类微相的蒸发盐总体积分数都保持 70%。

主要蒸发盐按饱和比驱动的溶解动力学处理。除石盐外，初始卤水不被强制到所有原生盐的共同热力学平衡（这样会产生不现实的极浓 Mg–B 卤水）；各动力学相改用初始卤水的饱和比作为亚稳态参考，只有补给混合使 `SR/SR_initial < 1` 时才启动溶解。这一“无背景溶解”阈值属于待校准假设，不能当作通用常数。Bischofite、Syngenite 和 Mirabilite 以零初始量平衡相表示，可在过饱和时沉淀。Li 在第一阶段不绑定未经证实的“含锂矿物”，而采用溶解 Li 加少量可交换位点；获得现场矿物学证据后，应再加入对应的 Li 固相和速率参数。

## 3. 反馈与对照

`feedback` 情景采用：

```text
矿物摩尔变化 × 摩尔体积 → 孔隙率变化
K_new = K_old × (phi_new / phi_old)^3
更新后的 phi、K、Pitzer 密度 → 下一水流/运移步
```

`fixed` 情景保留完全相同的流动边界、化学反应与密度计算，但不把矿物体积变化反馈给孔隙率和 K。两者成对比较可以隔离“优势通道反馈”，避免把普通弥散或矿物非均质误判为通道化。

注意：当前 SNIA 路径在每个反应步末提交介质变化，并在下一流动步生效；它不是流动—反应全耦合 Newton 解。默认启用密度反馈，但尚未加入盐度黏度反馈。

## 4. 运行

先执行已验证的短程检查：

```powershell
python examples\SaltLake_Brine3D\run.py --profile smoke --scenario feedback
python examples\SaltLake_Brine3D\validate.py --profile smoke --scenario feedback
python examples\SaltLake_Brine3D\plot.py --profile smoke --scenario feedback
```

正式运行用于优势通道判别的 30 年高分辨率对照组：

```powershell
python examples\SaltLake_Brine3D\run.py --profile highres --scenario feedback
python examples\SaltLake_Brine3D\run.py --profile highres --scenario fixed
python examples\SaltLake_Brine3D\plot.py --channels --profile highres
```

Pitzer 动力学计算成本较高。本机上每个 `highres` 30 年情景约需 4.5 小时。若只想隔离密度机制，可在运行、分析和验证命令中分别使用 `--no-density` 与 `--constant-density`。

## 5. 输出及指标

每个运行写入 `output/<profile>_<scenario>/`：

- `results.npy`、`results_headings.txt`、`results_times.npy`：离子、矿物、饱和指数和密度；
- `results_porosity.npy`、`results_K.npy`：反馈情景的介质演化；
- `case_metadata.json`：单位、网格、边界、初始/补给组成和固相品位；
- `well_quality.csv`：采卤井 K、Li 等离子浓度、富集倍数与 Br 突破比例；
- `mineral_inventory.csv`：各矿物的域总量及相对初始变化；
- `summary_metrics.json`：突破时间、峰值品位、反应体积和通道化指标；
- `overview.png`：第一层水头、K 浓度、溶解量、孔隙率、K/K0 与井水曲线。

`validate.py --compare` 另外生成同一时刻的井水 K、Li、Br 对照曲线和反馈—固定介质差值。

`validate.py` 检查全部时间步是否完成、MODFLOW 水量误差、矿物非负性、Pitzer 密度范围、孔隙率/K 物理范围，以及幂律反馈恒等式。验证通过只表示数值实现自洽，不代表参数已由现场资料验证。

## 6. 建议的参数试验矩阵

以 `feedback`/`fixed` 为每组必做对照，再改变：

1. 总抽水量：基准值的 0.5、1.0、1.5 倍；
2. 渠床电导：基准值的 0.1、1、10 倍，代表淤堵至高渗透渠床；
3. 井渠距离：约 0.5、1.0、1.5 倍基准距离；
4. K–孔隙率指数：2、3、5，并报告是否出现数值上过强的正反馈；
5. 矿物速率：每种主控钾盐的 0.1、1、10 倍；
6. 网格和月步：至少各做一组加密，确认突破时间和采出 K 峰值收敛。

主要响应量应至少包括 5% Br 突破时间、采出 K/Li 峰值与累计产出、反应体积、最大 K/K0、前 10% 单元贡献的 K 增量比例，以及每种矿物的累计溶解/沉淀量。

## 7. 进入真实矿区前必须替换的数据

- 三维地层、断层与非均质 K/Kz、储水参数；
- 实际渠水位、渠床厚度/渗透率、井位和分期抽水记录；
- 地层卤水完整分析、温度、密度和黏度；
- XRD/QEMSCAN 或其他定量矿物组成及固体 K/Li/B 品位；
- 批量/柱实验反演的矿物有效表面积和动力学常数；
- Li 的真实赋存相与交换参数；
- 现场水位、示踪剂和采出液品位曲线，用于独立校准与验证。
